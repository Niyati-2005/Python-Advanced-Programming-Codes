# Q2 – Student Performance Analytics

## Objective

Analyze student performance using study hours, attendance, participation, and total scores. The analysis includes statistical analysis, data visualization, and a Linear Regression model to predict student marks.

## Dataset

- **Source:** Kaggle
- **Dataset:** Student Performance Dataset
- **URL:** https://www.kaggle.com/datasets/nabeelqureshitiii/student-performance-dataset

## Libraries Used

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Analysis Performed

1. Loaded and inspected the dataset.
2. Checked for missing and duplicate values.
3. Cleaned the dataset.
4. Calculated descriptive statistics.
5. Created histograms for numerical variables.
6. Created boxplots to identify the distribution and potential outliers.
7. Analyzed the relationship between study hours and final marks.
8. Built a Linear Regression model.
9. Compared actual and predicted marks.
10. Evaluated the model performance.

## Visualizations

The analysis includes:

- Histograms
- Boxplots
- Study Hours vs Final Marks scatter plot
- Actual vs Predicted Marks plot

## Machine Learning

A Linear Regression model is used to analyze the relationship between study hours and student marks and to generate predicted marks.

## Conclusion

The analysis demonstrates how student study habits and other academic factors can be explored using statistical methods and visualization. Linear Regression provides a basic predictive model for estimating student performance.
