# Advanced Python Programming Codes

A collection of Python programs and data analysis projects developed as part of the **Advanced Python Programming** course.

This repository covers data cleaning, exploratory data analysis, statistical analysis, data visualization, outlier detection, and basic machine learning using Python.

---

## Projects

### Q1 – Air Quality Analysis

Analysis of air quality data using data cleaning, statistical analysis, and visualization techniques.

**Dataset:** [Air Quality Data in India – Kaggle](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india)

**File:** `Q1_Air_Quality_Analysis/Air_quality_analysis.py`

---

### Q2 – Student Performance Analytics

Analysis of student performance using study hours, attendance, participation, and academic scores, including Linear Regression.

**Dataset:** [Student Performance Dataset – Kaggle](https://www.kaggle.com/datasets/nabeelqureshitiii/student-performance-dataset)

**File:** `Q2_Student_Performance_Analytics/Student_performance_analysis.py`

---

### Q3 – Sales Forecasting Dashboard

Analysis of retail sales data including monthly revenue trends, best-selling categories, outlier detection, and revenue forecasting.

**Dataset:** [Retail Sales Data Dashboard – Kaggle](https://www.kaggle.com/datasets/josemiguelterron/retail-sales-data-dashboard)

**File:** `Q3_Sales_Forecasting/Sales_Forcasting_Dashboard.py`

---

### Q4 – Weather Trend Analysis

Analysis of weather trends using monthly averages, Z-score based hot-day detection, visualization, and Linear Regression.

**Dataset:** [Weather Data – Kaggle](https://www.kaggle.com/datasets/prasad22/weather-data)

**File:** `Q4_Weather_Trend_Analysis/Weather_Forecasting_dashboard.py`

---

### Q5 – Road Accident Analysis

Analysis of global road accident data to study accident severity, causes, injuries, fatalities, and other accident-related factors.

**Dataset:** [Global Road Accidents Dataset – Kaggle](https://www.kaggle.com/datasets/ankushpanday1/global-road-accidents-dataset)

**File:** `Q5_Road_Accident_Intelligence/Road_accident_analysis.py`

---
