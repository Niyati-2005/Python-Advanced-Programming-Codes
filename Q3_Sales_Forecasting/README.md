# Q3 – Sales Forecasting Dashboard

## Objective

Analyze retail sales data to identify sales trends, calculate monthly revenue, determine the best-selling product category, detect outliers, and forecast future revenue using Linear Regression.

## Dataset

- **Source:** Kaggle
- **Dataset:** Retail Sales Data Project
- **File:** Retail Sales Data Project.xlsx

## Libraries Used

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Analysis Performed

1. Loaded the Excel dataset.
2. Inspected the dataset structure.
3. Converted the Date column to datetime format.
4. Checked for missing and duplicate values.
5. Calculated monthly revenue.
6. Identified the best-selling product category.
7. Created time-series visualizations.
8. Detected revenue outliers using the IQR method.
9. Built a Linear Regression forecasting model.
10. Visualized future revenue predictions.

## Visualizations

The analysis includes:

- Monthly revenue time-series plot
- Category-wise sales comparison
- Revenue distribution
- Outlier visualization
- Future revenue forecast

## Machine Learning

Linear Regression is used to model the relationship between time and revenue and estimate future revenue.

## Conclusion

The analysis provides an overview of retail sales performance and revenue trends. The forecasting model demonstrates how historical sales data can be used to estimate future revenue and support business decision-making.
